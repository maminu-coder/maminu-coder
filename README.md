## 🔬 Research & Specializations

* **IoT Security & Malware Analysis:** Designing lightweight deep learning architectures (e.g., [HCL-Classifier](https://doi.org/10.1016/j.future.2022.12.034)) tailored for resource-constrained IoT environments.
* **Network Intrusion Detection (NIDS):** Feature fusion techniques using hybrid models like [CNN-GRU-FF](https://doi.org/10.1007/s40747-023-01329-4).
* **Adversarial Robustness:** Developing defense mechanisms against injection and evasion attacks in machine learning systems.
* **Generative AI & RAG:** Building knowledge-grounded LLM systems and self-hosted AI applications.
